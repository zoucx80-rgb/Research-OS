# Research OS v1.5.04 Migration Guide

Research OS v1.5.04 (code SemVer `1.5.4`) is a field-correctness PATCH. `CORE_API_VERSION` remains `1.0`; no database or Alembic migration is required.

## Delta comparison basis

Any ratio between delta facts now requires an explicit matching comparison basis. Add the corresponding facts:

```python
facts = {
    "delta_nwc": 60.0,
    "delta_nwc_comparison_basis": "2026H1_vs_2025H1",
    "delta_revenue": 100.0,
    "delta_revenue_comparison_basis": "2026H1_vs_2025H1",
    "delta_debt": 55.0,
    "delta_debt_comparison_basis": "2026H1_vs_2025H1",
}
```

The exact basis label is caller-defined but must be non-empty and identical for facts used in one ratio. Missing labels produce `COMPARISON_BASIS_REQUIRED`; unequal labels produce `COMPARISON_BASIS_MISMATCH`. The metric remains missing instead of silently mixing periods.

This affects incremental NWC intensity/IWCR, debt funding share, and total external-funding share. DSO/DIO/DPO and other existing period-day semantics are unchanged.

## Equity financing and dilution

The previous `delta_equity` name was economically ambiguous. v1.5.04 preserves it as reported book-equity change only:

```python
facts = {
    "delta_equity": 25.0,                    # accounting change; informational
    "external_equity_financing": 0.0,        # evidenced external funding amount
    "equity_dilution": False,                # evidenced dilution condition
    "external_equity_financing_comparison_basis": "2026H1_vs_2025H1",
}
```

Only `external_equity_financing` enters Funding Loop state and external-funding ratios. Only `equity_dilution=True` emits `EQUITY_DILUTION`. If external financing is unknown, omit it; do not insert zero merely to obtain a classified state.

`FundingLoopResult.reported_equity_change`, `comparison_basis_status`, and `comparison_basis_errors` are additive fields. Existing serialized results remain readable because all new fields have defaults.

## Thesis and valuation behavior

- `cfo`, `ocf`, and `operating_cash_flow` now resolve to the same operating-cash-flow falsifier value. New built-in theses emit `ocf`; old `cfo` falsifiers remain evaluable.
- Financing-thesis support is limited to evidence on the working-capital/financing drivers it uses.
- A distributor PE score receives a safety penalty only when the existing canonical Funding Loop is both debt-funded and negative-OCF. Routed models expose additive reason codes.

## Professional view

`ResearchViewPresenter` is now `professional-research-view@1.2.0`. The view adds read-only projections for Financial Sanity, Capital Efficiency, Forecast Discipline and the canonical next verification event. It does not recalculate completion, decision, thesis, funding or valuation state.

## Compatibility and deferrals

- `ResearchRunResult`, `ResearchCompletionGate`, legal decision states, Router taxonomy and Core API remain compatible.
- Conservative missing results may replace an old ratio/state when v1.5.03 inputs omitted comparison basis or explicit external-equity-financing semantics.
- Historical snapshots and release tags are unchanged.
- v1.5.04 adds no Hospitality Plugin, lease-adjusted valuation framework, advanced Manufacturing Plugin, Forecast rewrite, Evidence Quality engine or company-specific Core logic.

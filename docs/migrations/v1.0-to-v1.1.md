# Research OS v1.0 → v1.1 Migration

The migration is additive and does not rewrite historical calculated values.

| v1.0 field | v1.1 destination/default | Reversible |
|---|---|---|
| dataset_version | dataset_version | yes |
| parser_version | parser_version / `legacy-unknown` | yes |
| formula_version | formula_version | yes |
| valuation_version | valuation_version | yes |
| report_version | report_version | yes |
| — | research_os_version=`1.0.0` | yes |
| — | router_version=`legacy-manufacturing-default` | yes |
| — | kpi_pack_version=`legacy-manufacturing-default` | yes |
| — | driver_model_version=`legacy-none` | yes |
| — | forecast_version=`legacy-forecast` | yes |

Historical snapshots remain immutable. A v1.1 run creates a new snapshot rather than replacing a v1.0 snapshot.
